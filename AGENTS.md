# Acordos de desenvolvimento do AXIOM

- Antes de iniciar ou encerrar uma etapa, ler `AXIOM-roadmap.md` e `docs/progress.md`.
- Respeitar a sequência e os critérios de aceite. Dependências externas pendentes devem continuar identificadas; código preparado não equivale a integração validada.
- Organizar cada entrega em um commit com título em português e corpo explicando mudanças, verificações e limitações.
- Enviar cada entrega ao mesmo repositório `BanguelaDev/axiom`, sem forçar histórico. Se o push falhar, registrar o motivo e preservar o commit local.
- Atualizar `docs/progress.md` e `CHANGELOG.md` ao concluir a implementação de uma etapa.
- Manter uma aba visível da prévia local durante o trabalho. Reutilizar a aba existente; confirmar o servidor e o Fast Refresh antes de editar telas.
- Manter chaves e dados privados fora do Git e do app. Identificar cenários simulados como demonstração.
- Executar verificações adequadas a cada mudança. Para mobile, seguir também `apps/mobile/AGENTS.md`.
